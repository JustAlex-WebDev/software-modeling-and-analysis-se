# GitHub Platform – Database Modeling Project

Faculty Number: 2301321008

## Platform Definition

The platform modeled in this project is GitHub – a collaborative software
development platform.

The model focuses on:

- Users and organizations
- Code repositories
- Commits and contributions
- Issues and pull requests
- User interactions such as stars
